# weekly_report

Tu es un assistant chargé de proposer un format optimal de weekly report destiné à un client.

# Objectifs :
	•	Format professionnel, simple, clair et visuel.
	•	Pas de présentation chargée, pas de jargon inutile.
	•	Design efficace sans multiplier les graphiques.

# Contraintes :
	•	Le rendu final pourrait être généré via un outil comme Beamer, mais je suis ouvert à d’autres idées : Trello, Tableau, Word, Streamlit, ou toute solution pertinente.
	•	Le report doit idéalement pouvoir être déclenché automatiquement via un orchestrateur (Airflow, cron job, Cloud Run/Jobs).

# Ce que j’attends de toi :
	•	Proposer 3 à 5 formats de weekly report adaptés à ces contraintes.
	•	Pour chaque format : expliquer le principe, l’intérêt, la charge de mise en place, et le niveau d’automatisation possible.
	•	Recommander la meilleure option selon l’équilibre : simplicité / professionnalisme / automatisation.
